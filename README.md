# CSES Problem Set Solutions

Solutions to the [CSES Problem Set](https://cses.fi/problemset/) — a curated collection of competitive-programming problems maintained by the University of Helsinki.

## Categories

| Category | Problems |
|----------|----------|
| Introductory Problems | 19 |
| Sorting and Searching | 35 |
| Dynamic Programming | 19 |
| Graph Algorithms | 36 |
| Range Queries | 19 |
| Tree Algorithms | 16 |
| Mathematics | 31 |
| String Algorithms | 17 |
| Geometry | 7 |
| Advanced Techniques | 24 |
| Additional Problems | 56 |

## Layout

Each category is its own directory; solution files are named after the problem.

## Languages

Primarily C++ — CSES problems are tight on time/memory and C++ is the most idiomatic choice.
